- **Profile:** the reliability card was replaced by a per-group member score card (00021). On mobile the "Yo" tab now carries Avisos, Preferencias and Salir (`me-links.tsx`, SignOutButton).
- **Settings:** there are now 7 notification toggles (adds `match_created`, `results_request` and `results_reminder`), a DeviceNotifications (web push) section, and a Paper/Board/System theme control. The default theme is dark.
- **PWA:** the SW is now network-only plus Web Push (push, `notificationclick`, `pushsubscriptionchange`). It no longer does offline caching. The top bar still has no `safe-area-inset-top` while `statusBarStyle` is `black-translucent` on iOS.
- **Auth and landing:** they render inside PublicFrame, which is always the dark board and has no footer. The auth forms use shared Input, PasswordInput and Label.
- **Notification prefs:** they now gate device push on the server (00022). `emit_notification` can no longer be called by clients.

### Redesigned features
- **Results entry:** each player now files a blind report (`report-form.tsx`, `submit_match_report`). A weighted consensus (`recompute_match_consensus`) combines them and moves through pending/provisional/consensus/locked. The admin editor became "edit and lock" / "reopen"; there's no direct delete-and-reinsert anymore.
- **Finishing a match:** it happens automatically through the `scheduled_jobs` job `auto_finish` at start time + duration (00019). The manual finish now has a confirmation Sheet.
- **MVP:** voting moved into the report form. Votes are weighted by role (admin 1.5, captain 1.25, member 1.0) and you can't vote for yourself. `mvp_count` and the badge only count once the result reaches consensus or is locked.
- **Stats, reliability and rating:** counters are rebuilt from scratch on every recompute, and badges that no longer apply are revoked. There's a new `ejemplar` badge. `reliability_score` is replaced by `member_score` (00021). `overall_rating` is replaced by the admin/captain-only `player_rating_summary` fed by `peer_ratings` (00018).
- **Scheduler:** the old single daily cron is now a job queue plus `/api/cron/tick`, `scripts/ticker.ts` and a tick triggered by page traffic. The daily cron is only a fallback.
- **Notification delivery:** device Web Push (00022) is filtered by per-user prefs and audience. `emit_notification` can no longer be called by regular users. Only the first open announces `match_created`, and only the first publish announces `teams_created`.
- **WhatsApp:** manual sharing (text or image via share-actions and whatsapp-share) is now the main path. The webhook is an optional "advanced" setting.
- **Bell and notifications page:** the header bell is gone. The unread count now shows as a dot in the tab bar/sidebar and in the "Me" links. New types were added: `rate_new_member`, `member_score_*` and the `results_*` family.
